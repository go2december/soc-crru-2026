# รายงานผลการตรวจสอบและวิเคราะห์โครงสร้างข้อมูล สาขาวิชาหลัก และแขนงวิชา/วิชาเอก

> [!NOTE] สรุปผลการตรวจสอบเชิงลึก (Executive Summary)
> จากการตรวจสอบความสัมพันธ์ของข้อมูลในฐานข้อมูลจริง (`soc_db`) ทั้งตาราง `departments`, `programs`, `staff_profiles`, และ `program_instructors` พบข้อเท็จจริงสำคัญและโอกาสในการปรับปรุงสถาปัตยกรรมเพื่อรองรับการแยกแขนงวิชา รูปแบบการเรียน (4 ปี / เทียบโอน) และการกระจายสิทธิ์ (RBAC) ดังต่อไปนี้

---

## 1. ผลการตรวจสอบความสัมพันธ์ในฐานข้อมูล (Database Audit Findings)

### 1.1 ความเชื่อมโยงระหว่างสาขาวิชา (`programs`) และภาควิชา (`departments`)
- ในตาราง `departments` มีหน่วยงานวิชาการ 6 สาขาวิชาอย่างครบถ้วน:
  - ID 6: `สาขาวิชาสังคมศาสตร์` (อาจารย์ 4 ท่าน)
  - ID 7: `สาขาวิชานวัตกรรมการพัฒนาสังคม` (อาจารย์ 3 ท่าน)
  - ID 8: `สาขาวิชาคหกรรมศาสตร์` (อาจารย์ 4 ท่าน)
  - ID 9: `สาขาวิชาจิตวิทยาสังคม` (อาจารย์ 3 ท่าน)
  - ID 10: `สาขาวิชาภูมิศาสตร์และภูมิสารสนเทศ` (อาจารย์ 4 ท่าน)
  - ID 11: `สาขาวิชายุทธศาสตร์การพัฒนาภูมิภาค` (อาจารย์ 2 ท่าน)
- ⚠️ **สิ่งที่ตรวจพบ**: ในตาราง `programs` ทั้ง 7 รายการ ปัจจุบันค่า **`department_id` ยังเป็น `NULL`**
  - *แนวทางแก้ไข*: ทำการ Map ค่า `department_id` ของแต่ละหลักสูตรให้ตรงกับตาราง `departments` เพื่อให้ระบบสิทธิ์ (RBAC) สามารถตรวจสอบได้ทันทีว่า **บุคลากรสังกัดสาขาวิชาใด มีสิทธิ์แก้ไขหลักสูตรและแขนงวิชาใดบ้าง**

## 2. การวิเคราะห์มิติ "สาขาวิชาหลัก" vs "แขนงวิชา/วิชาเอก" และ "รูปแบบการศึกษา"

จากการวิเคราะห์ พบว่าโครงสร้างการจัดการศึกษาของคณะฯ สามารถจัดกลุ่มความสัมพันธ์ออกเป็น 3 รูปแบบหลัก:

### กลุ่มที่ 1: สาขาวิชาที่มี "วิชาเอก" และมี "รูปแบบเทียบโอน 2 ปีหลัง" ชัดเจน (High-Variation)
- **สาขาวิชาคหกรรมศาสตร์ (`home-eco`)**:
  - **วิชาเอก 1**: วิชาเอกการประกอบอาหารและบริการ (Culinary and Service)
  - **วิชาเอก 2**: วิชาเอกคหกรรมศาสตร์ประยุกต์ (Applied Home Economics)
  - **รูปแบบการศึกษา (Study Modes)**:
    1. **แผน 4 ปี ปกติ** (132 หน่วยกิต): รับผู้จบ ม.6 / ปวช.
    2. **แผนเทียบโอน / ต่อเนื่อง (2 ปีหลัง)** (ประมาณ 66–72 หน่วยกิต): รับผู้จบ ปวส. ด้านอาหารและโภชนาการ หรือ คหกรรมศาสตร์
  - **ความต้องการด้านสื่อ**: แต่ละวิชาเอกมีแล็บครัว หรือสตูดิโองานฝีมือแยกกัน จึงต้องมี **วิดีโอ YouTube แกลเลอรีภาพผลงาน และช่องทาง TikTok/IG เฉพาะวิชาเอก**

### กลุ่มที่ 2: สาขาวิชาที่มี "แขนงวิชาเฉพาะทาง" ในระดับปริญญาตรี (Specialized Tracks)
- **สาขาวิชาสังคมศาสตร์ (`social-sci`)**:
  - **แขนงที่ 1**: แขนงวิชาสังคมวิทยาและมานุษยวิทยา (Sociology and Anthropology)
  - **แขนงที่ 2**: แขนงวิชาการจัดการทรัพยากรทางวัฒนธรรม (Cultural Resource Management)
  - **รูปแบบการศึกษา**: แผน 4 ปีปกติ (130 หน่วยกิต)
  - **ความต้องการด้านสื่อ**: วิจัยภาคสนามชุมชน, การจัดการมรดกทางวัฒนธรรม, สื่อคลิปสารคดีสั้น และ Facebook/TikTok เผยแพร่งานวัฒนธรรม

### กลุ่มที่ 3: สาขาวิชาหลักสูตรเดี่ยว (Single Curriculum)
- **นวัตกรรมการพัฒนาสังคม (`social-dev`)**: 128 หน่วยกิต
- **ภูมิศาสตร์และภูมิสารสนเทศ (`gis`)**: 135 หน่วยกิต (แล็บ GIS, รีโมตเซนซิง, โดรนสำรวจ)
- **จิตวิทยาสังคม (`social-psych`)**: 126 หน่วยกิต (การทดสอบทางจิตวิทยา, จิตวิทยาองค์กร)
- *ลักษณะ*: สามารถเปิดเป็นหลักสูตรเดี่ยว หรือในอนาคตหากมีการเปิดกลุ่มวิชาเฉพาะทาง เช่น GIS เปิดแขนง Drone Mapping ก็สามารถเพิ่ม Track เข้าสู่ตารางใหม่ได้ทันที

### กลุ่มที่ 4: ระดับบัณฑิตศึกษา (Graduate Studies)
- **สาขาวิชายุทธศาสตร์การพัฒนาภูมิภาค**:
  - **ระดับปริญญาโท (`regional-dev-ma`)**: ศศ.ม. 36 หน่วยกิต
  - **ระดับปริญญาเอก (`regional-dev-phd`)**: ปร.ด. 48 หน่วยกิต
  - *สังกัด*: Department ID 11 เดียวกัน อาจารย์ประจำหลักสูตรสามารถดูแลร่วมกันได้ทั้งระดับโทและเอก

## 4. แผนปฏิบัติการที่ชัดเจน (Concrete Action Plan)

1. **เชื่อมโยง `department_id` ในตาราง `programs`**: อัปเดต `department_id` ให้ทั้ง 7 หลักสูตร เพื่อเป็นรากฐานของระบบสิทธิ์ (RBAC)
2. **สร้างตาราง `program_tracks`**:
   - รองรับ `program_id` (FK), `code`, `name_th`, `name_en`, `track_type`, `study_plan_type` (`REGULAR_4YR`, `TRANSFER_2YR`, `GRADUATE`)
   - รองรับสื่ออิสระ: `banner_url`, `youtube_video_url`, `social_links` (Facebook, TikTok, Instagram, YouTube, Line), `gallery_images`, `curriculum_url`
3. **ระบบสิทธิ์ (Departmental RBAC Guard)**:
   - ตรวจสอบ `user.departmentId === program.departmentId` ให้บุคลากรในสาขาเข้าแก้ไขได้เฉพาะสาขาตนเอง
