# 📝 มาตรฐานเนื้อหา ข่าวสาร และคลังวิชาการ (Content & Repository)

> แนวทางการผลิตเนื้อหา, ข่าววิจัย, หน้าอาจารย์/นักวิจัย, บริการวิชาการ, MOOC และการจัดทำ Institutional Repository

---

## 📰 1. ข่าวประชาสัมพันธ์และข่าวเชิงวิชาการ

- [ ] **6.1.1** ข่าวมีชื่อเรื่อง (Title) ที่ชัดเจนและมี Keyword สำคัญ
- [ ] **6.1.2** มีสรุปสาระสำคัญ (Executive Summary) ในย่อหน้าแรก 3-5 บรรทัด
- [ ] **6.1.3** ระบุองค์ประกอบครบถ้วน: วัตถุประสงค์, กิจกรรมที่ทำ, ผลลัพธ์ที่ได้ และประโยชน์ต่อสังคม
- [ ] **6.1.4** รูปภาพประกอบมี Alt Text อธิบายภาพ
- [ ] **6.1.5** มีไฟล์เอกสารแนบหรือลิงก์เชื่อมโยงไปยังผลงาน/รายงานเต็ม
- [ ] **6.1.6** ข่าวและผลงานสำคัญมี **ฉบับภาษาอังกฤษ** เพื่อรองรับการอ้างอิงสากล

---

## 🔬 2. งานวิจัยเด่น (Research Highlight)

- [ ] **6.2.1** มีชื่อผลงานวิจัยทั้ง **ภาษาไทยและภาษาอังกฤษ**
- [ ] **6.2.2** ระบุชื่อนักวิจัย, หน่วยงานสังกัด, ลิงก์ Google Scholar และ ORCID ชัดเจน
- [ ] **6.2.3** อธิบายสาระ 4 ด้าน: ปัญหาที่ศึกษา, วิธีดำเนินงาน, ผลการค้นพบ และผลกระทบต่อวิชาการ/สังคม
- [ ] **6.2.4** มีลิงก์ไปยังรายงานฉบับสมบูรณ์, บทความวารสาร หรือรหัส DOI ถาวร
- [ ] **6.2.5** มีรูปแบบการอ้างอิงผลงาน (Citation format) ที่พร้อมให้ผู้อื่นคัดลอกไปอ้างอิงได้ทันที

---

## 👨‍🏫 3. ทำเนียบอาจารย์และนักวิจัย (Faculty & Researcher Profiles)

- [ ] **6.3.1** มีข้อมูลพื้นฐาน: ชื่อ-นามสกุล (ไทย-อังกฤษ), ตำแหน่งวิชาการ, สังกัด และอีเมลมหาวิทยาลัย (`@crru.ac.th`)
- [ ] **6.3.2** ระบุความเชี่ยวชาญพิเศษ (Areas of Expertise) และประเด็นวิจัยที่สนใจ
- [ ] **6.3.3** มีลิงก์เชื่อมโยงไปยัง **Google Scholar Profile, ORCID** และ **Scopus Author ID**
- [ ] **6.3.4** แสดงรายการผลงานวิจัยและบทความตีพิมพ์ย้อนหลัง 5 ปี
- [ ] **6.3.5** แสดงรายการโครงการวิจัย หนังสือ ตำรา สิทธิบัตร และงานบริการวิชาการเด่น

---

## 🤝 4. หน้าโครงการบริการวิชาการและนวัตกรรมชุมชน

- [ ] **6.4.1** ระบุพื้นที่ดำเนินงาน ชุมชนเป้าหมาย และหน่วยงานภาคีร่วม
- [ ] **6.4.2** อธิบายปัญหาของพื้นที่ บริบทชุมชน และกระบวนการแก้ปัญหา
- [ ] **6.4.3** แสดงผลลัพธ์ที่วัดผลได้ชัดเจน ทั้งเชิงปริมาณ (จำนวนผู้รับประโยชน์) และเชิงคุณภาพ
- [ ] **6.4.4** มีคู่มือ สื่อการเรียนรู้ ชุดความรู้ หรือรายงานให้ดาวน์โหลดไปใช้ประโยชน์ต่อได้
- [ ] **6.4.5** มีลิงก์ที่หน่วยงานภายนอก/เครือข่ายสามารถนำไปอ้างอิงกลับมาได้

---

## 💻 5. หน้าหลักสูตรออนไลน์ (MOOC & Digital Learning)

- [ ] **6.5.1** มีชื่อรายวิชา คำอธิบายรายวิชา (Course Outline) และประวัติผู้สอน
- [ ] **6.5.2** ระบุผลลัพธ์การเรียนรู้ (Learning Outcomes), จำนวนชั่วโมงเรียน และกลุ่มเป้าหมาย
- [ ] **6.5.3** แสดงโครงสร้างบทเรียนและวิธีการลงทะเบียนเข้าเรียนชัดเจน
- [ ] **6.5.4** หน้าแนะนำรายวิชา (Landing page) **เปิดให้ Google ค้นพบและทำดัชนีได้** (ไม่ซ่อนทั้งหมดไว้หลังระบบ Login)

---

## 🏛️ 6. คลังปัญญาและผลงานวิชาการ (Institutional Repository)

> [!tip] **ตัวอย่าง Google Scholar Meta Tags ในหน้าเอกสารวิชาการ**
> ```html
> <meta name="citation_title" content="Development of STEAM Learning Innovation for Small Schools">
> <meta name="citation_author" content="Wichit Thepprasit">
> <meta name="citation_publication_date" content="2026">
> <meta name="citation_pdf_url" content="https://repository.crru.ac.th/files/steam-learning-2026.pdf">
> ```

- [ ] **7.1** มีหน้าเว็บ HTML เฉพาะสำหรับผลงานแต่ละรายการ (Single Item Landing Page) ไม่เปิดเฉพาะไฟล์ PDF ลอยๆ
- [ ] **7.2** มีชื่อเรื่องผลงานทั้งภาษาไทยและภาษาอังกฤษ
- [ ] **7.3** มีชื่อผู้แต่ง สังกัด บทคัดย่อ คำสำคัญ ปีที่เผยแพร่ และ Persistent Identifier / DOI
- [ ] **7.4** ลิงก์ดาวน์โหลด PDF เปิดให้ Search Engine Crawler เข้าถึงได้โดยตรง ไม่บังคับ Login
- [ ] **7.5** ไฟล์ PDF เป็นรูปแบบที่ค้นหาข้อความได้ (Searchable Text PDF) ไม่ใช่ภาพสแกนล้วน
- [ ] **7.6** มี Meta tags ตามมาตรฐาน Google Scholar ครบถ้วน (`citation_title`, `citation_author`, `citation_publication_date`, `citation_pdf_url`)
- [ ] **7.7** โครงสร้างหน้าเว็บแยก 1 หน้าต่อ 1 ผลงาน ไม่รวมหลายเรื่องในหน้าเดียว
