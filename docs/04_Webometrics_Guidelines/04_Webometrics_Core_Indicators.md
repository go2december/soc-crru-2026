# 📊 เช็กลิสต์ตามตัวชี้วัด Webometrics และการติดตามผลรายเดือน

---

## 🎯 1. เช็กลิสต์ 3 มิติหลักของ Webometrics

### 🌐 1. Visibility / Impact (สัดส่วน 50%)
- [ ] มีหน้าโครงการถาวร (Permanent Project Landing Page) ที่แชร์และอ้างอิงได้
- [ ] หน่วยงานร่วม/ภาคีเครือข่ายสามารถสร้าง Backlink ลิงก์กลับมายังหน้าโครงการใน `crru.ac.th`
- [ ] มีหน้าบันทึกข้อตกลงความร่วมมือ (MOU), กิจกรรมเครือข่าย และเอกสารการประชุมวิชาการ (Conference Proceeding) ภายใต้โดเมนมหาวิทยาลัย
- [ ] มีเอกสาร คู่มือ ชุดกิจกรรม หรือ Dataset ที่เปิดให้หน่วยงานภายนอกนำไปใช้งานจริง
- [ ] มีพื้นที่จัดแสดงนวัตกรรม (Innovation Showcase) และผลกระทบต่อชุมชน (Community Impact)

### 📖 2. Openness / Transparency (สัดส่วน 10%)
- [ ] อาจารย์และนักวิจัยทุกคนมี **Google Scholar Profile แบบ Public**
- [ ] บุคลากรใช้อีเมลมหาวิทยาลัย (`@crru.ac.th`) ในการยืนยันตัวตนในระบบ
- [ ] ระบุชื่อหน่วยงานสังกัด *"Chiang Rai Rajabhat University"* ให้ถูกต้องและตรงกันทุกท่าน
- [ ] มีการตรวจสอบผลงานซ้ำซ้อนหรือผลงานที่ระบบจับคู่ผิดคนสม่ำเสมอ
- [ ] นักวิจัยมีรหัส **ORCID** และนำมาเชื่อมโยงกับหน้าโปรไฟล์บนเว็บไซต์หลัก

### 🏆 3. Excellence (สัดส่วน 40%)
- [ ] มีฐานข้อมูลรวบรวมผลงานตีพิมพ์ในฐาน **Scopus** ของหน่วยงาน
- [ ] ตรวจสอบความถูกต้องของ **Scopus Author ID** ของอาจารย์ทุกคน
- [ ] มีแผนงานและเงินทุนสนับสนุนบทความกลุ่ม **Scopus Q1 / Q2** และบทความวิจัยร่วมกับต่างประเทศ
- [ ] มีระบบพี่เลี้ยงบทความวิจัย (Mentorship) และงบประมาณสนับสนุนการตรวจภาษาทางวิชาการ
- [ ] ติดตามจำนวนการอ้างอิง (Citations) รายบทความ และจัดทำเป็น Research Highlight เผยแพร่

## 📈 2. ตัวชี้วัดที่ต้องติดตามผ่าน Dashboard ทุกเดือน

| ตัวชี้วัดสำคัญ | เครื่องมือ / แหล่งข้อมูล | วัตถุประสงค์การติดตาม |
| :--- | :--- | :--- |
| **จำนวนหน้าที่ถูก Index & ปัญหา Indexing** | Google Search Console | ตรวจสอบว่าหน้าเว็บใหม่ถูก Search Engine บันทึกและไม่มี Error |
| **สถานะ Sitemap และ Robots.txt** | Google Search Console & URL Inspection | ป้องกันไม่ให้บอทถูกบล็อกโดยไม่ตั้งใจ |
| **จำนวน Broken Links (ลิงก์เสีย)** | Broken Link Checker / Automated Script | ป้องกันปัญหา 404 ที่ลดทอนความน่าเชื่อถือของเว็บ |
| **External Backlinks & Referring Domains** | Majestic, Ahrefs, Semrush หรือเครื่องมือมหาวิทยาลัย | วัดคะแนน Impact / Visibility สู่โดเมน `crru.ac.th` |
| **จำนวน Google Scholar Profile & ORCID** | สำรวจจากคณะ / ระบบฐานข้อมูลบุคลากร | เพิ่มความโปร่งใสและคะแนน Openness |
| **จำนวนผลงานใน Institutional Repository** | ระบบคลังปัญญา (DSpace / Custom Repository) | สะสมผลงานวิชาการของสถาบัน |
| **จำนวนบทความ Scopus Q1/Q2** | Scopus Database / สถาบันวิจัย | ขับเคลื่อนคะแนน Excellence |
| **จำนวนข่าววิจัยภาษาอังกฤษ & Research Highlight** | เว็บไซต์มหาวิทยาลัย / PR Dashboard | สื่อสารสู่ประชาคมวิจัยสากล |
