# ⚙️ มาตรฐานและเช็กลิสต์ด้านเทคนิคและ SEO (Technical & SEO)

> ครอบคลุมการตั้งค่าโดเมน ความปลอดภัย Search Console การคุมบอท และประสิทธิภาพเว็บ

---

## 🌐 1. โดเมนและโครงสร้างเว็บไซต์ (Domain & Architecture)

- [ ] **4.1.1** เว็บไซต์อยู่ภายใต้โดเมนหลัก `*.crru.ac.th`
- [ ] **4.1.2** ไม่มีการใช้เว็บไซต์ฟรี (เช่น Wix, Blogger ฟรี, Google Sites นอกโดเมน) หรือโดเมนส่วนตัวเป็นเว็บหลัก
- [ ] **4.1.3** โครงสร้าง URL อ่านง่ายและสื่อความหมาย (Clean & Semantic URLs) เช่น `/research`, `/faculty`, `/services`
- [ ] **4.1.4** มีลิงก์ย้อนกลับ (Backlink Header/Footer) ไปยังเว็บไซต์หลักมหาวิทยาลัย `https://www.crru.ac.th`
- [ ] **4.1.5** มีเมนูโครงสร้างพื้นฐานครบถ้วน: งานวิจัย, บุคลากร, ข่าวประชาสัมพันธ์, บริการวิชาการ, เอกสารดาวน์โหลด
- [ ] **4.1.6** ไม่มีเว็บไซต์เก่าหลายเว็บที่มีเนื้อหาซ้ำซ้อนกัน (Duplicate Content)
- [ ] **4.1.7** เว็บไซต์เก่าที่เลิกใช้ ได้ทำ **HTTP 301 Permanent Redirect** ส่งผู้ใช้และบอทมายัง URL ใหม่แล้ว

---

## 🔒 2. ความปลอดภัยและการเข้าถึง (Security & Mobile Friendliness)

- [ ] **4.2.1** เว็บไซต์บังคับใช้งาน **HTTPS (SSL/TLS)** ทุกหน้า
- [ ] **4.2.2** เปิดผ่าน `http://` แล้วมีระบบ Auto Redirect ไปยัง `https://` อัตโนมัติ
- [ ] **4.2.3** ใบรับรองความปลอดภัย (SSL Certificate) ยังไม่หมดอายุและต่ออายุอัตโนมัติ
- [ ] **4.2.4** เว็บไซต์แสดงผล Responsive ได้อย่างสมบูรณ์ทั้งคอมพิวเตอร์และมือถือ (Mobile-Friendly)
- [ ] **4.2.5** ขนาดตัวอักษรบนมือถืออ่านง่าย สบายตา ไม่ต้องใช้การซูมหน้าจอ
- [ ] **4.2.6** เมนูและปุ่มบนมือถือกดง่าย (Tap target เหมาะสม) ไม่เกิดปัญหา Layout ซ้อนทับ

## 🤖 3. Sitemap และ Robots.txt (Search Engine Crawling)

> [!tip] **ตัวอย่างไฟล์ robots.txt ที่ถูกต้อง**
> ```txt
> User-agent: *
> Allow: /
> Sitemap: https://www.crru.ac.th/sitemap.xml
> ```
> *(หลีกเลี่ยง `Disallow: /` กับเว็บไซต์หลักโดยเด็ดขาด)*

- [ ] **4.3.1** มีไฟล์ `sitemap.xml` ที่อัปเดตอัตโนมัติ
- [ ] **4.3.2** `sitemap.xml` บรรจุ URL สำคัญครบถ้วน (ข่าวสาร, วิจัย, บุคลากร, คลังปัญญา)
- [ ] **4.3.3** ส่ง `sitemap.xml` เข้าสู่ **Google Search Console** เรียบร้อยแล้ว
- [ ] **4.3.4** มีไฟล์ `robots.txt` อยู่ที่ root directory
- [ ] **4.3.5** `robots.txt` ไม่ได้สั่งบล็อกหน้าสำคัญที่ต้องการให้ Search Engine จัดทำดัชนี
- [ ] **4.3.6** ไม่ใช้คำสั่ง `Disallow: /` กับเว็บไซต์หลัก

## 🔍 4. SEO พื้นฐาน & Structured Data (On-Page SEO)

- [ ] **4.4.1** ทุกหน้ามี `<title>` ชัดเจนและระบุชื่อหน่วยงาน/มหาวิทยาลัย
- [ ] **4.4.2** ทุกหน้ามี `<meta name="description">` อธิบายสาระสำคัญอย่างกระชับ
- [ ] **4.4.3** จัดลำดับโครงสร้างเนื้อหาถูกต้อง: มี `<h1>` เพียง 1 จุด และมี `<h2>`/`<h3>` ตามลำดับชั้น
- [ ] **4.4.4** รูปภาพทุกรูปมีคุณสมบัติ `alt="..."` อธิบายเนื้อหาของภาพ
- [ ] **4.4.5** ตั้งชื่อไฟล์รูปภาพและ PDF ด้วยคำที่มีความหมายและอ่านเข้าใจง่าย
- [ ] **4.4.6** มี Internal Link เชื่อมโยงไปยังหน้าบทความหรือบริการที่เกี่ยวข้อง
- [ ] **4.4.7** กำหนด `<link rel="canonical">` ในทุกหน้า เพื่อป้องกันปัญหา Duplicate Content
- [ ] **4.4.8** ฝัง **Structured Data (JSON-LD / Schema.org)** เช่น `Organization`, `Article`, `Course`, `Person`, `Event`

---

## ⚡ 5. ความเร็วและคุณภาพการใช้งาน (Web Performance & Core Web Vitals)

- [ ] **4.5.1** หน้าแรกโหลดรวดเร็ว (LCP < 2.5s) ไม่ใช้ไฟล์วิดีโอหรือภาพแบนเนอร์ขนาดใหญ่เกินจำเป็น
- [ ] **4.5.2** ภาพประกอบและภาพข่าวถูกบีบอัด (WebP/Optimized format) ก่อนอัปโหลด
- [ ] **4.5.3** ไฟล์เอกสาร PDF ถูกบีบอัดให้อยู่ในขนาดเหมาะสม โหลดและเปิดอ่านได้ง่าย
- [ ] **4.5.4** ไม่มีลิงก์เสีย (No Broken Links / 404 Errors) ในหน้าข้อมูลสำคัญ
- [ ] **4.5.5** มีรอบการตรวจเช็ก Broken Links อย่างสม่ำเสมออย่างน้อยเดือนละ 1 ครั้ง
