# 📋 นโยบาย แผนปฏิบัติการ และโครงสร้างการกำกับดูแล Webometrics
> แหล่งข้อมูลอ้างอิง: *Cybermetrics Lab, OpenAlex, Scimago-Scopus, Majestic*

---

## 🏛️ 1. นโยบายที่ควรประกาศใช้ระดับมหาวิทยาลัย

| นโยบาย | คำอธิบายเชิงปฏิบัติ |
| :--- | :--- |
| **1. ตั้งคณะกรรมการ Webometrics & Digital Visibility** | มีคณะกรรมการถาวร กำหนดเป้าหมาย ติดตามผล และรายงานผู้บริหารทุกเดือน |
| **2. ใช้โดเมนหลัก `crru.ac.th` เป็นศูนย์กลาง** | เว็บไซต์คณะ ศูนย์ สำนัก วารสาร โครงการ และคลังปัญญาต้องอยู่ภายใต้โดเมนหลัก เพื่อสะสม Domain Authority ร่วมกัน |
| **3. จัดทำ Institutional Repository & Research Portal** | รวบรวมบทความ รายงานวิจัย วิทยานิพนธ์ ตำรา ชุดข้อมูล และนวัตกรรม พร้อมใส่ Metadata ครบถ้วน |
| **4. กำหนดมาตรฐาน Google Scholar และ ORCID** | บุคลากรสายวิชาการต้องมี Google Scholar (Public) และ ORCID โดยระบุสังกัด *"Chiang Rai Rajabhat University"* ให้เป็นมาตรฐานเดียวกัน |
| **5. ผลักดันงานวิจัยระดับคุณภาพ Excellence** | สนับสนุนบทความ Scopus Q1/Q2, งานวิจัยร่วมต่างประเทศ, บริการตรวจภาษา และระบบพี่เลี้ยงบทความวิจัย |

## 👥 2. โครงสร้างการกำกับและบทบาทหน่วยงาน

- **ผู้บริหารมหาวิทยาลัย:** กำหนดเป้าหมาย อนุมัตินโยบาย และกำกับการรายงานผล
- **ศูนย์ไอที / สำนักวิทยบริการ:** ดูแลโดเมน, HTTPS, Sitemap, Robots.txt, Technical SEO และจัดทำ Webometrics Dashboard
- **สถาบันวิจัยและพัฒนา (สวพ.):** รวบรวมงานวิจัย Scopus, Researcher Profile, Research Highlight, คลังปัญญา (Metadata, OAI-PMH, DOI, Google Scholar discovery)
- **งานประชาสัมพันธ์ / สื่อสารองค์กร:** ผลิตข่าวสารเชิงวิชาการภาษาไทยและอังกฤษ พร้อมทำ Internal/External links กลับสู่เว็บหลัก
- **คณะ / ศูนย์ / สำนัก:** ตรวจสอบความสมบูรณ์ของเว็บไซต์ตนเอง ส่งข้อมูลบุคลากร โครงการ ผลงาน และเอกสารเข้าสู่ระบบกลาง

## 📅 3. แผนดำเนินงาน (Roadmap 3 เดือน & 12 เดือน)

### 🔹 แผนดำเนินงาน 3 เดือนแรก (Quick-win Infrastructure)
- [ ] **เดือนที่ 1:** รวบรวม URL เว็บไซต์ทุกหน่วยงาน ระบุผู้ดูแล ตรวจสอบโดเมน HTTPS sitemap และสถานะการอัปเดต $\rightarrow$ *ผลลัพธ์: ทะเบียนเว็บไซต์และรายการเว็บที่ต้องปรับปรุง*
- [ ] **เดือนที่ 2:** เปิด HTTPS, สร้าง sitemap, ตรวจ robots.txt, แก้ broken links, ตั้งค่า 301 redirect และปรับ Title/Description หน้าแรก $\rightarrow$ *ผลลัพธ์: เว็บสำคัญพร้อมให้ Crawler เข้าถึงอย่างถูกต้อง*
- [ ] **เดือนที่ 3:** ปรับปรุงหน้าแรก หน้าข่าว บุคลากร วิจัย บริการวิชาการ และหน้าดาวน์โหลด $\rightarrow$ *ผลลัพธ์: หน้าเว็บสำคัญมี SEO พื้นฐานครบถ้วน*

### 🔹 แผนดำเนินงานระยะยาว 12 เดือน (Full Cycle Evolution)
- [ ] **เดือน 1-2:** สำรวจ แก้ปัญหาพื้นฐาน รวมโดเมน และปรับ SEO Technical
- [ ] **เดือน 3:** จัดทำ Directory หน้าอาจารย์, เชื่อมโยง Google Scholar Profile และ ORCID
- [ ] **เดือน 4:** พัฒนาระบบ Institutional Repository และฝัง Metadata มาตรฐานสากล
- [ ] **เดือน 5:** ผลิต Research Highlight ภาษาไทยและอังกฤษ สม่ำเสมอเพื่อสร้าง Backlinks
- [ ] **เดือน 6-12:** ใช้งาน Webometrics Dashboard ติดตามผลทุกเดือน และพัฒนาคุณภาพงานวิจัยต่อเนื่อง
